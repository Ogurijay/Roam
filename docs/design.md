# Roam 设计文档

> 一套键鼠，控制多台电脑。在面前的直接切屏，不在身边的远程看画面。跨网络、低延迟、开源（AGPL-3.0）。

## 1. 目标

| 模式 | 场景 | 会话内容 |
|---|---|---|
| **A 实体屏** | 多台电脑都在面前，网络可能不通（VPN / 热点 / AP 隔离 / 跨 VLAN） | 输入 + 剪贴板 |
| **B 远程屏** | 电脑不在身边 | 输入 + 剪贴板 + 视频（+ 音频） |

每台设备只装一个 Agent，可以同时当控制端和被控端。A/B 只是布局里给设备做的标记，可以随时切换。

平台优先级：**Windows ↔ macOS** > Linux。

## 2. 连接策略（无自建服务器）

按优先级自动选择，UI 上实时显示当前路径和 RTT：

1. 局域网直连（mDNS）
2. 公网 P2P 打洞（iroh；公共中继只用于协调，打通后数据直连）
3. 公网 IPv6 直连
4. 用户自己的公网机器当中继（Agent 内置中继模式）
5. iroh 公共中继兜底（海外，150–300ms，B 模式基本不可用）

另外支持直接填写 Tailscale / ZeroTier / EasyTier 的虚拟 IP。

注意：Clash 等代理开启 TUN 模式时会干扰 UDP 打洞，需要把 Roam 设为直连。

## 3. 通道（单条 QUIC 连接复用）

| 通道 | 传输 | 优先级 |
|---|---|---|
| 鼠标移动 | 不可靠数据报，只保留最新的 | 最高 |
| 按键 / 点击 | 可靠有序流 + 定期按键状态核对（防卡键） | 最高 |
| 视频 / 音频 | 数据报 + FEC | 高 |
| 控制信令 | 可靠流 | 中 |
| 剪贴板 / 文件 | 可靠流，限速 | 低 |

防卡键：切屏、断线、心跳超时时，被控端释放所有已按下的键。

## 4. 输入

- 按键统一用 **USB HID Usage** 传物理扫描码，不传字符，目标机的输入法照常工作。
- 修饰键映射按"方向"配置，默认 Win→Mac 时 Ctrl↔Cmd 对调。
- 滚轮区分"行滚动"和"像素滚动"（Mac 触控板）。
- A 模式：由控制端算好虚拟桌面坐标，换算成目标机的逻辑点后注入（绝对坐标）。
- B 模式 / 游戏模式：传原始相对位移。

| 平台 | 采集 | 注入 | 权限 / 坑 |
|---|---|---|---|
| Windows | Raw Input + `WH_KEYBOARD_LL` / `WH_MOUSE_LL` | `SendInput` | SYSTEM 服务 + 安全桌面工作进程；Ctrl+Alt+Del 用 `SendSAS` |
| macOS | `CGEventTap` | `CGEventPost` | 辅助功能、输入监控、屏幕录制三项权限需要引导授权 |

## 5. 远程画面（B 模式）

延迟预算：采集 1–4ms → 编码 3–8ms → 网络 RTT/2 → 解码 2–5ms → 渲染 0–8ms。

| 环节 | Windows | macOS |
|---|---|---|
| 采集 | DXGI Desktop Duplication | ScreenCaptureKit |
| 编码 | NVENC / QSV / AMF | VideoToolbox |
| 解码渲染 | D3D11VA → D3D11 | VideoToolbox → Metal |

- **本地绘制光标**：远程画面里不画光标，控制端在本地直接绘制，鼠标移动零延迟。
- 编码：不用 B 帧、使用帧内刷新、低延迟码率控制、不缓冲；默认 H.264，双方支持时用 HEVC。
- 动态码率；桌面静止时降低帧率。

## 6. 安全

- 每台设备有自己的密钥对（即 iroh EndpointId），配对时交换公钥并固定。
- 全程端到端加密（QUIC/TLS），中继只转发密文。
- 本地管理接口只监听 127.0.0.1。

## 7. 路线图

| 里程碑 | 内容 |
|---|---|
| **M0 连通性** | `roam-probe`：实测打洞成功率、路径类型、RTT 分布 |
| **M1 键鼠核心** | Win↔Mac A 模式、边缘切换 + 快捷键、Cmd/Ctrl 映射、防卡键、文本剪贴板、配对码 |
| **M2 远程画面** | B 模式、硬件编解码、本地光标、动态码率 |
| **M3 好用** | 布局编辑器（Tauri）、图片/文件剪贴板、状态浮窗、Windows 安全桌面 |
| **M4 管理** | 内置中继模式、设备分组/场景、吊销、自动更新 |

## 8. 参考
