被其他电脑控制本机作为被控端

Mac 鼠标与触摸板

相对于当前系统方向反转。主控、被控角色都有效；本机硬件产生的滚动在留在本机或发往其他电脑前统一处理，Roam 远程输入不重复反转。Magic Mouse、部分平滑滚动鼠标也属于连续滚动组。

跨设备键盘映射

按物理按键映射，不改变本机打字。未单独设置的按键沿用原来的 Cmd / Ctrl 对调规则。接收端开启的自定义规则优先于发送端；修改规则会先返回主机并释放已按下按键。

Mac 按 MacBook 常用布局列出，不含数字小键盘。Fn + Delete、Fn + 方向键按系统产生的 Delete / Home / End / Page Up / Page Down 事件映射。Fn / 地球键本身、Touch ID、亮度和媒体功能暂不提供自由重映射。

发送到其他电脑

右键发送文件

支持多选文件和文件夹。选择接收电脑后立即发送，收到的文件保存在「下载/Roam」，同名文件会另存。被控端之间通过主机转发；双方和主机均需 Roam v0.3.3 或更新版本。

锁屏控制

Windows 锁屏后，普通程序收不到远程键鼠。启用后会安装一个系统服务（需要管理员确认一次），锁屏时也能用主机的键鼠输入密码解锁。只在锁屏界面生效，不处理管理员确认（UAC）弹窗。
