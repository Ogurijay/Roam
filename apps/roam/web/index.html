锁屏控制

Windows 锁屏后，普通程序收不到远程键鼠。启用后会安装一个系统服务（需要管理员确认一次），锁屏时也能用主机的键鼠输入密码解锁。只在锁屏界面生效，不处理管理员确认（UAC）弹窗。
